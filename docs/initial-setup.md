# 初期設定チェックリスト

## 1. 管理者アカウント

- 初回ログインは `admin` / `admin`。
- ログイン直後にパスワードを変更する。
- 実運用では管理者用と通常作業用のアカウントを分ける。

## 2. プロジェクト機能

各プロジェクトで次を有効にする。

- Work packages
- Gantt charts
- Time and costs

## 3. チケット種別

最初は以下の4種類に絞る。

| 種別 | 用途 |
| --- | --- |
| フェーズ | 工程単位の親チケット |
| タスク | 通常作業 |
| 課題 | 調査・判断が必要な問題 |
| マイルストーン | 納期、レビュー、リリース |

## 4. ステータス

| ステータス | 意味 |
| --- | --- |
| 未着手 | 着手前 |
| 対応中 | 作業中 |
| 確認待ち | レビューや顧客確認待ち |
| 保留 | 外部要因で進められない |
| 完了 | 対応済み |

## 5. 必須入力ルール

チケット登録時:

- 担当者
- 開始日
- 終了日
- 予定工数
- 親チケットまたは対象フェーズ

工数登録時:

- 対象チケット
- 作業日
- 実績工数
- 作業分類
- 短いコメント

## 6. 日常運用

- 作業者は当日中に工数を入力する。
- リーダーは週1回、ガントチャートで遅延と依存関係を確認する。
- 予定工数と実績工数の乖離が大きいチケットは、原因をコメントに残す。
- プロジェクト横断の状況確認には、複数プロジェクトのガント表示を使う。
